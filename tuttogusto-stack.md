# Стек для сайта кофейни «Туттогусто»

## Фронтенд
- **Next.js (React) + TypeScript** — SSR/SSG для скорости и SEO
- **Tailwind CSS** — быстрая адаптивная вёрстка
- **Framer Motion** — анимации карусели, hover-эффекты карточек блюд
- `next/image` — автоматическая оптимизация и ленивая загрузка картинок

## Данные
- **PostgreSQL** (или **SQLite** для MVP/старта) — хранение меню, цен, новостей, категорий
- Простая самописная админка на Next.js (`/admin`) для редактирования контента без разработчика

## Хостинг
- Свой хостинг (уже есть) — там держим API/админку, которая пишет в БД
- Публичную часть сайта можно дополнительно собрать статикой (`output: 'export'`) и разместить на **GitHub Pages** — подойдёт и как обычный сайт, и как источник для Telegram Mini App (Telegram грузит любую HTTPS-страницу в WebView)

## Пока не включено (на будущее)
- Система оплаты (ЮKassa / Т-Касса) — добавим на следующем этапе
- Headless CMS (Strapi/Directus) — заменили на прямую работу с Postgres/SQLite
- Стек Telegram-бота — определим после вёрстки сайта
